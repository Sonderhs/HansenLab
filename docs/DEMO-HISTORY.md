# Hansen Lab 概念 Demo

2026-10-18，独立实验分支 `codex/hansen-lab-demo`。

## 范围

根据用户讨论确认的方向制作：Hansen Lab 个人品牌、三维玻璃档案首页、技术与项目为主并兼容随笔。复用原有 Blender 资产、基线材质、自由平面拖动与惯性、选档波浪和抽取规则。

独立入口和 Vite 配置位于 `demo/hansen-lab/`。三维引擎增加可选标签身份参数，默认保持原品牌；Demo 构建单独解析自己的数据适配模块。正式文章数据、启动流程与构建入口未替换。本轮不合并或推送 main，不部署正式站点。

## 体验

- `npm run dev:hansen`：http://127.0.0.1:5174/
- 首页：拖动、滚轮、方向键、分类和行按钮；Enter 打开文章。
- `/` 打开目录，标题／标签／摘要搜索，分类筛选；项目入口直接筛选项目实践。
- 文章：`#post/lab-017` 等独立 hash 链接，可刷新和分享本机 URL；含目录、代码块与复制、进度、下一篇。
- 返回保留当前选档；阅读时三维退场过渡完成后暂停绘制。
- 减少动态效果跟随系统，也可通过首页按钮切换。本 Demo 不持久化用户设置。

## 验证

- `npm run build:hansen` 通过，包含 Demo 和原项目的 TypeScript 检查；输出 `release/hansen-lab-demo/`。
- Playwright CLI 在 Windows Chromium 实际渲染，验证三维载入、分类记忆、文章进入／返回、目录搜索与空结果恢复、分类组合筛选、结果跳转、文章直达链接刷新、关于弹窗与输入恢复、系统减少动态效果。
- 1600×900 桌面目视检查；390×844、320×700 及 844×390 视口检查无横向页面溢出、品牌导航无重叠、标题在容器内。手机长标题使用完整换行，桌面保留原有滚动文字。
- 桌面与手机文章截图已目视检查。截图及本轮浏览脚本在本机 `output/playwright/hansen/`，排除 Git。
- 最终浏览验证无 JavaScript 异常。Three.js 沿用现有的 PCFSoftShadowMap 弃用提示；构建提示 Three.js bundle 超过默认大小阈值。

## 原型限制

40 篇示例文章、日期、阅读时长和个人介绍均为演示内容，页面明确标识；不代表用户的真实成果或发表历史。五列×八篇适配原有场景的固定槽位，正式博客需另行解耦内容数量。

未接入写作后台、真实文章、评论、统计或 RSS；hash 文章地址用于演示，正式 SEO 与静态文章路径留待架构阶段。手机结果属于 Chromium 视口模拟，未进行真实 iPhone / Safari 性能与触摸验收。

## 2026-10-18 · 首轮性能优化

用户反馈卡顿后授权测量和优化。测试 Chromium 实际使用 AMD Radeon 核显，通过 WebGL 调试扩展读取；不根据机器装有 RTX 3050 就假定浏览器在使用独显。

### 改动

- Demo 启用阵列近到远的实例提交，利用深度测试减少被遮挡表面的材质运算；不改变实例物理位置、数量、波浪、抽取高度或材质参数。
- 主场景增加可选 `ArchiveRenderPass`，只对完整不透明输出的阵列表面预写深度。折射背景仍使用独立捕获；选中与归位模型、程序化解密、半透明标签不参与预写。正式主页默认不开启这两项，原片对照保持原顺序。
- 目录和关于窗口打开时立即暂停三维循环，正文显示后也立即暂停；关闭或返回时重置帧时钟并恢复，避免补跑隐藏期间的时间。指针提示隐藏时不再写入位置样式。
- Demo 将动画时间步长上限由 50ms 提高至 250ms；已有阻尼为解析形式，避免低帧率时动作用比实际更慢的时间推进。正式主页仍沿用 50ms 上限。
- 新增显式原始／流畅切换，默认原始。流畅复用既有性能预设，不与减少动态效果绑定；原始可完整恢复。没有静默降低默认画质。
- 修正搜索输入框有内容时 Esc 可能仅清空输入、没有关闭目录的问题；弹窗截获 Esc，防止再传递到背后的文章。

### 相同画质下的测量

Windows Chromium，667×871 CSS 像素、DPR 1.5，最终渲染 1000×1306；32 次 AO、2048 阴影、完整景深与折射均保持。依次运行基线→优化→基线→优化，每轮预热 3 秒，首页停留与连续切档各约 3.5 秒。未锁定 GPU 频率、功耗或其他桌面负载，数值不外推为所有设备的固定提升。

| 场景            | 基线两轮 FPS  | 优化两轮 FPS  |
| --------------- | ------------- | ------------- |
| 首页持续呼吸    | 11.69 / 12.11 | 14.29 / 13.77 |
| 每约 450ms 切档 | 8.73 / 8.53   | 10.50 / 10.55 |

同一 WebGL 上下文对固定画面单独采集 GPU 计时：阵列总渲染约 40.10→30.55ms，详情约 54.51→29.55ms。GPU 时间使用 `EXT_disjoint_timer_query_webgl2`，未就绪或 disjoint 查询不视作零。这是强制绘制固定画面的开销，不能直接当作实际 FPS；渲染提交次数由 98 增至 103，收益来自减少昂贵片段计算，并非减少三角形。

流畅预设的一次连续切档样本约 22.54 FPS。它明确改变了画质，因此不与上表合并作为「同画质优化收益」。核显完整画质仍达不到 60 FPS，不能声称已经彻底解决流畅性。

关闭代理创建的采样浏览器后，只读检查用户当前内置预览的 DOM 诊断数据，确认同样使用 AMD Radeon 核显；当时完整画质窗口为 1001×1307，约 26 FPS，CPU 提交均值约 3.77ms。该值是瞬时观测，不能与上表受控交替样本混算，也不代表稳定帧率。此检查未切换用户的画质或系统设置。
