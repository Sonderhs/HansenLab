# 浏览交互音效

2026-10-22。用户反馈开场有声但浏览无声，补齐同一原项目的交互提示音。

| 操作 | 原项目音效 |
| --- | --- |
| 选档（按钮、键盘、滚轮、自由拖动和惯性） | tick 玻璃轻碰 |
| 切列 | column 玻璃声，方向按钮保留左右声像 |
| 打开文章／返回阵列 | open／back 玻璃抽取与归位 |
| 目录／关于打开和关闭 | page-open／page-close 电子提示 |
| 筛选、系列页签、正文目录定位 | ui-tick |
| 开启声音、画质／动效设置、成功复制代码 | confirm |

开场与浏览复用 src/boot-audio.ts 管理的同一 AudioContext、音量、压限和本地偏好，沿用 hansen.boot-sound 键兼容已有选择。页脚「音效」统一静音；在首页开启立即给一次确认反馈，无需重播开场。没有接入背景音乐。

首次访问默认静音；保存开启的用户刷新后，画面和文章直达仍不自动发声，在下一次真实指针或键盘交互中解锁。初始化选档、重复选择当前文章和悬停不发声；正文路由同步选档时关闭额外选档声，避免一次打开叠加重复玻璃提示。原音色与合成参数未修改，恢复原项目 tick／column 的 55ms 限流及最多十个并发声音。

后台停止当前声音并暂停设备，下一次浏览操作恢复。设备恢复期间仅保留最近一次交互，静音、重播、后台或释放取消积压动作。减少动态效果仅跳过开场音效，浏览提示音仍由声音开关独立控制。
